Start it

# 1. Start it. The web interface is inside the program.
./bitvoice

# 2. A browser opens on the setup wizard (or open https://127.0.0.1:8443). Until you install your own
#    certificate, the browser warns once about BitVoice's self-signed one; continue to the site.

# 3. Point a SIP phone at this computer, port 5060, with the extension's number and password.
#    Or press the phone button at the bottom of any screen. Dial *43 for the echo test.

On Windows, unzip and double-click bitvoice.exe; keep its window open while you use it. Windows asks once whether BitVoice may use the network: allow it on private networks so phones can connect.

The programs are pure Go with no C libraries, so they run on any Linux, Alpine and distroless images included.

Check what you downloaded

Against SHA256SUMS:

shasum -a 256 -c SHA256SUMS --ignore-missing

Signed releases. Every program carries BioDream's release key and comes with its signature beside it. The Updates page installs only programs signed with that key, so a forged or damaged file is refused. The public key (ed25519, base64):

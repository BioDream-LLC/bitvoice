Leaving FreePBX

A FreePBX and Asterisk alternative you run from the browser

FreePBX is a web interface for Asterisk. BitVoice is a phone system with its own engine and its own web interface in one program: nothing to assemble, and every setting on a screen.

How they differ

BitVoiceFreePBX on Asterisk
What you installOne program for Linux, macOS or Windows; SQLite inside, PostgreSQL for several serversAsterisk, FreePBX, a web server, PHP and a database on Linux, usually from a distribution image

What comes over

On Import, upload the exports; BitVoice shows exactly what would change before anything is applied, and the import is a revision you can undo.

  • FreePBX: Admin → Bulk Handler → Export → Extensions (CSV)
  • Asterisk: pjsip.conf or sip.conf
  • Also 3CX, Cisco Unified CM, Avaya IP Office and Communication Manager, and Mitel MiVoice Business
  • Voicemail PINs, names and email addresses come over when the export has them; exports carry no SIP passwords, so each extension gets a new one, and trunks arrive switched off until you enter their passwords

The usual FreePBX feature codes work (*72, *78, *8, *97 and the rest) and can be changed. Day/night toggles (FreePBX's call flow control), PIN sets, caller ID lookup and DISA are there. IAX2 trunks join an Asterisk or FreePBX server you keep, so you can move one site or department at a time, and tools written for Asterisk's AMI and ARI can drive BitVoice too.

What BitVoice does not do yet

  • BRI ISDN cards, E&M and MFC-R2 signalling, and SS7. BRI lines connect through a SIP gateway instead.
  • On PRI: DMS-100 release link transfer and advice of charge.
  • Converting G.723.1 (it is passed through when both ends speak it).
  • A long list of real phones, carriers and cards tried in production: see what has been tested.

The step-by-step guide to the import is in the manual.
